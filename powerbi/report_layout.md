# 报表设计（4 页）

> 每页都写明：给谁看、回答什么问题、用什么视觉对象、放哪些字段。
> 按这个搭，不需要自己再想布局。

---

## 页 1 · 运营总览

**给谁看**：运营负责人，每天早上扫一眼
**回答**：这个季度生意怎么样？量、价、效率哪个在动？

### 布局（16:9，上中下三段）

**上段 · 5 张 KPI 卡**（横向排列，等高）

| 卡片 | 度量值 | 副标签 |
|---|---|---|
| GMV | `[GMV]` | 环比 `[行程量环比]` |
| 行程量 | `[行程量]` | 环比 |
| 客单价 | `[客单价]` | — |
| 平均速度 | `[平均速度_mph]` | 速度偏离 `[速度偏离]` |
| 机场单占比 | `[机场单占比]` | — |

> 卡片用「新式卡片」视觉对象，能同时显示值和环比箭头。旧的「卡片」只能放一个数。

**中段 · 左 2/3：日度趋势折线**
- X 轴：`dim_date[date_key]`
- Y 轴：`[行程量]`
- 辅助线：`[同星期基线]`（虚线）
- 说明：两条线贴近 = 正常，分开 = 异动

**中段 · 右 1/3：支付方式环形图**
- 图例：`dim_payment[payment_name]`
- 值：`[行程量]`
- 为什么放这里：支付结构变化往往是计价或结算问题的前兆，放总览页能第一时间发现

**下段 · 左：距离分层堆叠柱**
- X 轴：`dim_date[year_month]`
- 图例：`fact_trips[distance_band]`
- 值：`[行程量]`
- 用途：看需求结构是不是在短途化

**下段 · 右：行政区条形图**
- Y 轴：`dim_zone[borough]`
- X 轴：`[行程量]`
- 排序：降序
- 数据标签：`[区域占比]`

### 交互
- 顶部放一个日期切片器（`dim_date[date_key]`，范围选择）
- 点击任意视觉对象，其他对象联动筛选

## 页 2 · 异动监控

**给谁看**：值班分析师
**回答**：今天有没有异常？异常在哪一天、哪个维度？

### 布局

**上段 · 5 张告警卡**

| 卡片 | 度量值 | 条件格式 |
|---|---|---|
| 2-13 偏离度 | `[2-13 偏离度]` | < −16% 显示红色 |
| 2-13 缺口单量 | `[2-13 缺口单量]` | 负值红色 |
| 2-13 缺口营收 | `[2-13 缺口营收]` | 负值红色 |
| 2-13 速度偏离 | `[2-13 速度偏离]` | 正值标蓝 |
| 2-13 行程量 | `[2-13 行程量]` | — |

> 条件格式在「格式 → 条件格式 → 字体颜色 → 规则」里设，阈值用上面给的。

**中段 · 全宽：偏离度柱状图**
- X 轴：`dim_date[date_key]`
- Y 轴：`[偏离度]`
- 零线：加一条分析线在 0
- 条件格式：正值绿、负值红
- 用途：一眼看出哪些日子偏离了基线

**下段 · 左 1/2：异动日明细表**

| 列 | 字段 |
|---|---|
| 日期 | `dim_date[date_key]` |
| 星期 | `dim_date[dow]` |
| 行程量 | `[行程量]` |
| 同星期基线 | `[同星期基线]` |
| 偏离度 | `[偏离度]` |
| 缺口营收 | `[缺口营收]` |

按 `ABS([偏离度])` 降序排，只显示 Top 10（用「筛选器 → 前 N 项」）。

**下段 · 右 1/2：量 vs 速度散点图**
- X 轴：`[平均速度_mph]`
- Y 轴：`[行程量]`
- 详细信息：`dim_date[date_key]`
- 用途：**这张图只能排除“拥堵”**。量跌但速度不降，说明不是路被堵住；但它不能区分“需求收缩”和“司机不出车”——两者观测可以完全一样。要区分，必须再接司机在线数、叫车请求数、等待时长。

## 页 3 · 异动下钻（以 2-13 为例）

**给谁看**：做归因的人
**回答**：这次异动到底发生在哪个时段、哪个区域、哪类订单？

### 顶部筛选
- 日期切片器锁定 `2024-02-13`（可选；PBIP 已用 2-13 事件度量，不锁也能得到正确值）

### 布局

**左上 · 分时段对比柱状图**
- X 轴：`fact_trips[hour_of_day]`
- Y 轴：`[2-13 行程量]` 和 `[2-13 同星期基线]` 两个度量值（不是图例；原生柱状图不能把两个度量值放进图例）
- 说明：看跌幅的形状——早高峰跌最狠更像通勤需求消失，但这只是假设；全时段均匀下跌则更像整体收缩

**右上 · 距离分层对比**
- X 轴：`fact_trips[distance_band]`
- Y 轴：`[2-13 偏离度]`
- 数据标签：开
- 说明：短途抗跌、长途跌幅大 → 需求结构短途化

**左下 · 行政区偏离度条形图**
- Y 轴：`dim_zone[borough]`
- X 轴：`[2-13 偏离度]`
- 排序：按偏离度升序（跌最狠的在上）
- 数据标签：`[2-13 缺口单量]`
- 说明：Bronx −57.6% / Brooklyn −56.5% 会排在前面，这是策略的抓手；但 Bronx 体量小，只作信号

**右下 · 机场 vs 市区对比**
- 用两张卡片或一个小柱状图
- 度量值：`[2-13 偏离度]`，按 `fact_trips[is_airport]` 分组
- 说明：两者跌幅接近 → 不是机场需求单独消失

## 页 4 · 策略看板

**给谁看**：调度决策者
**回答**：明天/下次极端天气，车该往哪投？

### 布局

**左 · 区域运力建议表**

| 列 | 内容 | 来源 |
|---|---|---|
| 行政区 | `dim_zone[borough]` | 维度 |
| 基准日均 | `[2-13 同星期基线]` | 度量值 |
| 当前日均 | `[2-13 行程量]` | 度量值 |
| 偏离度 | `[2-13 偏离度]` | 度量值 |
| 建议收缩比例 | `[2-13 偏离度]` | 度量值（不能写成计算列：计算列不能引用度量值） |
| 超额缺口（单） | `[2-13 超额缺口]` | 度量值；区域超额 = 实际 − 基线 × (1 + 整体偏离度)，Manhattan 约 −563 |

> 「建议收缩比例」直接用该区的偏离度：在确认需求侧收缩后，跌 57.6% 的 Bronx / 56.5% 的 Brooklyn 才按相应比例收缩，而不是跟着大盘收 32%。

**右 · 短途/长途效率对比**

- 双轴图：左轴 `[行程量]`，右轴 `[平均时长_分钟]`
- X 轴：`fact_trips[distance_band]`
- 说明：短途单周转快（9.8 分钟）vs 10+ mi（44.3 分钟；5–10 mi 为 27.4 分钟），单量约 4.5 倍；但每小时营收不是最高（2-13 短途 $127.5/h vs 10+ mi $153.3/h）。若目标是司机收入，不能单方面倾斜短途。

**下 · 可优化空间瀑布图**

展示逻辑：整体缺口 → 减去不可抗部分 → 得到可优化空间 → 按区域/时段拆分

| 步骤 | 值 |
|---|---|
| 总缺口 | −31,362 单 |
| 行业性冲击（按整体跌幅） | 已含 |
| Brooklyn 超额缺口 | −190 单 |
| 早高峰超额缺口 | −1,303 单 |
| **可优化合计** | **−1,493 单** |

> 瀑布图用「瀑布图」视觉对象，类别放维度名，值放缺口。

## 通用规范

**配色**
- 主色 `#2C6E9B`（深蓝），强调色 `#B03A2E`（暗红），中性 `#9AA5AD`（灰）
- 负向指标一律红色，正向绿色。不要用默认配色，默认的蓝色系分不清主次

**字号**
- 页面标题 20pt，视觉对象标题 12pt，数据标签 9pt

**交互**
- 每页左上角放「返回总览」按钮（书签跳转）
- 页 2 和页 3 之间用「钻取」连接：点页 2 的异动日，右键「钻取 → 异动下钻」

**刷新**
- 数据源是 CSV，Power BI 里配「文件夹」连接器，ETL 重跑后点刷新即可
- 如果以后接数据库，把 CSV 换掉，度量值不用改
